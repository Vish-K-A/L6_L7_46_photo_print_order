# L6_L7_46 — Photo Print Order

Lab 7: Fuzz Testing

## About

A small Python module that parses print orders, averages file sizes and works out the payable amount after a discount.

## Files

| File | Description |
|------|-------------|
| `photo_print_order.py` | The code under test |
| `test_photo_print_order.py` | Starter test file |

## Completed fuzzing solution

The completed input-validation solution and its Hypothesis tests are in
`processor.py` and `test_processor.py`. Install their dependencies and run the
tests from this folder:

```bash
python -m pip install -r requirements.txt
python -m pytest -v test_processor.py
```
